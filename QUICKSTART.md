# Quick Start Guide

## 5-Minute Quick Start

### Step 1: Install Package

```bash
python -m pip install --upgrade hydrosebench
```

Python 3.10 or later is required. To install from a downloaded repository instead, run `python -m pip install ./hydrosebench-eval` from its root directory.

### Step 2: Run First Example

Download the repository for its example scripts and `test.csv`, then run from the repository root:

```bash
cd examples
python example_1_basic_evaluation.py
```

## Core Features Demonstration

### Feature 1: Batch Evaluate Multiple Models

```python
from hydrosebench import evaluate_all_models, create_summary_excel, load_benchmark_from_file
from pathlib import Path

# Run from the repository root; use the demonstration's standard answers.
benchmark = load_benchmark_from_file("examples/test.csv")
summary = evaluate_all_models(
    "examples/test.csv",
    benchmark=benchmark,
    output_dir="./results"
)

# Generate summary report
create_summary_excel(summary, Path("./results"), benchmark)
```

The demonstration includes five missing standard answers and five missing model answers per model. These cases are marked `Unscored`. The seven recorded conclusions meaning "no correct option" or "no correct answer" disagree with valid standard answers and are counted as `Incorrect`. The test file differs from the complete official dataset and is provided only to exercise the code; see [the example documentation](examples/README.md) for expected results.

### Feature 2: View Evaluation Results

```python
# View rankings of all models
for idx, result in enumerate(summary["results"], 1):
    accuracy = "N/A" if result["accuracy"] is None else f"{result['accuracy']:.2%}"
    print(f"{idx}. {result['model_name']}: {accuracy}; unscored={result['unscored_count']}")
```

## Output Files

After running batch evaluation, the following will be generated:

1. **Model Detailed Reports**: `<model_name>/score_report.xlsx`, `<model_name>/score_report.json`, and `<model_name>/score_report.csv`
2. **Model Comparison Summary**: `models_comparison.xlsx`, generated by the `create_summary_excel` call shown above
3. **Summary Data**: `all_models_summary.json`
4. **Separate Issue Details**: `<model_name>/score_report_issues.csv`; Excel reports also include an `Issues` worksheet
